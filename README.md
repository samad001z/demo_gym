# Fitness Edge Demo

This repository contains a private, non-indexable demo for a gym website.

The demo uses placeholder contact details and general fitness copy. It is not
an official business site and must not be used to publish unapproved claims,
personal details, pricing, reviews, or medical outcomes.

## Development

```bash
npm install
npm run dev
```

The production build is available with `npm run build` and can be served with
`npm start`.
